Reading the slopes

Amplitude separates the operators; order does not

All 40 fitted slopes land within 1.2% of −2, with the worst correlation coefficient at 0.99982 — these are straight lines, not approximately straight ones. No operator, lattice or storage convention is buying an extra order of accuracy, and none is losing one either.

The ordering by amplitude is consistent across both cases: TRT < CM ≈ MRT < BGK. That TRT wins in a periodic bulk flow is not a contradiction of the central-moment results elsewhere — the magic parameter tunes the third-order modes that CM and MRT send straight to equilibrium. On an off-axis shear wave the ordering reverses.

D2Q5 and D3Q7 are absent by construction. They have no isotropic fourth-order moments, cannot support Navier–Stokes, and have no fluid solver to converge; they arrive with the thermal module.

Method

How these numbers were produced

Both flows are exact solutions of the incompressible Navier–Stokes equations, so the reference is analytic rather than a fine-grid extrapolation. Each run marches half an e-folding of the decay, then reports the relative L2 error of the velocity field and the effective viscosity recovered from the decay rate. Slopes are least-squares fits of log error against log N over the whole ladder — five points for Taylor–Green, four for ABC — not pairwise ratios.

Peak velocity scales as 1/N so the O(Ma²) compressibility error stays second order alongside the spatial error; holding it fixed instead would flatten every curve toward first order and measure the wrong thing. Streaming is Esoteric Pull with shifted populations throughout, in FP64. The axis is grid points per direction — against total node count the same data would show slope −2/D.

Reproduce with ./build/validation/grid_convergence, which emits this data as CSV in about 43 seconds.
